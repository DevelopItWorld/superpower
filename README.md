# 🛠️ Windows Technician Toolkit

A lightweight and easy-to-use **Windows Batch Toolkit** designed to provide quick access to useful Windows tools, system diagnostics, network utilities, maintenance commands, and system information — all from a simple interactive CMD menu.

## ✨ Features

* 🖥️ Open CMD & PowerShell
* ⚙️ Access Registry Editor, Services & Event Viewer
* 👤 Manage Local Users
* 📋 Open Group Policy & Computer Management
* 🔄 System Restore & Recovery Settings
* 🛡️ Windows Security
* 🌐 IP Configuration & Internet Connectivity Test
* 🛣️ Network Route / Tracert
* 🔍 Windows System File Verification
* 💻 Windows Version & System Information
* 📂 View Recent Files
* 🧹 Clean Temporary Files
* 💾 Explore Temporary Files
* 🔋 Generate & view Battery Health Reports
* 🎭 Fun CMD animations

## 🎯 Purpose

This project is created as a **simple Windows technician/utility toolkit** for students, beginners, and users who want quick access to commonly used Windows commands and diagnostic tools without remembering multiple commands.

## ⚠️ Important Note

Some options open advanced Windows utilities such as **Registry Editor, Group Policy, Services, and Computer Management**. Make changes carefully, as incorrect system configuration can affect Windows.

The toolkit is intended for **educational, troubleshooting, and system-maintenance purposes**.

## 💻 Requirements

* Windows 10 / Windows 11
* Command Prompt
* PowerShell
* Internet connection for the online ASCII animation options

## 🚀 How to Use

1. Download or clone this repository.
2. Run the `.bat` file.
3. Select an option from the menu.
4. Follow the instructions shown in CMD.
